# Borozdov Terracotta

A theme from the Borozdov collection. Two faces — light **Cinnamon**, a warm parchment
notebook with a terracotta pen, and dark **Firebrick**, the same notebook by lamplight.
Cream paper, a single terracotta accent, indigo and green riding along as quieter asides.

![Borozdov Terracotta in light mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/terracotta/main/screenshots/light.png)

![Borozdov Terracotta in dark mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/terracotta/main/screenshots/dark.png)

## Principles

- **Cream paper, not cold white.** Both faces sit on a warm canvas — parchment cream in
  Cinnamon, charred umber in Firebrick — never a neutral grey.
- **One pen, one colour.** Terracotta is the single saturated accent: links, the filled
  button, the checked box. Nothing else on the page reaches for it.
- **Indigo and green as asides.** Code, tags and callouts carry a quiet second and third
  voice — indigo for structure, green for confirmation — so the page never reads as
  monochrome, but never competes with the terracotta pen either.
- **A hairline builds every card.** Callouts, code panes, tables and popovers share the
  same card language: a mist fill, a 1px rim, generous corners, and — on modals and
  popovers only — the soft three-layer shadow of a raised sheet of paper.
- **Developer-native type.** The platform's own sans at 400 for text and 600–700 for
  headings; no embedded font, no load, no flash of unstyled text.

## Features

- Light and dark modes, following Settings → Appearance → Base color scheme
- Callouts colour themselves by type — info in blue, todo and question in indigo, tip and
  success in green — through Obsidian's own `color-mix`, never a flat grey card
- Tags and property pills as full dust-chip pills that pick up terracotta under the pointer
- A toggle thumb tuned per face so it never disappears against its own track
- Text colours meet WCAG contrast on both faces
- The phone layout keeps the same colours and shapes
- No embedded fonts, so the theme stays around 12 KB
- No `!important`: every rule can be overridden with a CSS snippet

## Installation

**From the community directory, as a variant:** this theme ships inside **Borozdov
Ember**. Install Borozdov Ember under Settings → Appearance → Themes → Manage, then the
[Style Settings](https://github.com/mgmeyers/obsidian-style-settings) plugin, and choose
**Terracotta** under Style Settings → Borozdov Ember → Variant. The variant brings this
theme's palette, type and corners; its own layout, and its embedded font if it has one,
come with the full theme below.

**The full theme, by hand:** download `manifest.json` and `theme.css` from the
[latest release](https://github.com/borozdov-obsidian-themes/terracotta/releases/latest) into
`<vault>/.obsidian/themes/Borozdov Terracotta/`, then choose Borozdov Terracotta under
Settings → Appearance → Themes.
